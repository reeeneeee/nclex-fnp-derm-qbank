# Brief for question writers
Student: FNP student prepping for boards (AANP/ANCC style, NCLEX-format items). Source material: projects/nclex-fnp-derm-qbank/source.txt (pediatric primary care textbook excerpt). READ the sections for your topics fully before writing.

Write EXACTLY 50 questions for your assigned topics. Mix: ~25 Select-All-That-Apply (SATA) and ~25 single best answer, interleaved.

DIFFICULTY: very very hard. That means:
- Clinical vignettes (age, history, exam, timeline) — not "what is X" recall.
- Answer options must look nearly identical: same length, same grammatical form, differing by one detail (a duration, a dose, a timing, an age cutoff, a body location, a drug class, "before vs after", "2 weeks vs 4 weeks", "24 hours vs 48 hours").
- Test fine distinctions from the source: exact durations, age cutoffs, monitoring intervals, exclusion rules, what is spared vs involved, what NOT to do, contraindicated combos, differential look-alikes.
- SATA: 5–6 options, 2–4 correct, distractors that are "almost right" (right drug wrong duration, right finding wrong location).
- Single choice: 4 options A–D.
- Spread items across all your topics roughly evenly; don't repeat the same fact twice.
- Accuracy matters more than anything. Base correct answers on the source text. If the source states something that conflicts with current standard guidance (e.g., the source claims Wood's lamp fluoresces most tinea corporis — in reality most dermatophytes causing tinea corporis do NOT fluoresce; Microsporum does), do not build a question whose correct answer depends on the dubious claim. Where your topic's source text is missing/truncated (e.g., fifth disease), use standard, well-established pediatric/FNP references.

FORMAT (markdown, exactly this, no extra commentary before/after):

**Q<number>. [SATA]** <stem — end SATA stems with "Select all that apply.">
A. ...
B. ...
C. ...
D. ...
E. ...

**Answer:** A, C, E
**Rationale:** <2–5 sentences: why each correct option is correct AND why the tempting distractors are wrong, citing the specific detail that makes them wrong.>

---

Single-choice items use **[Single]** instead of **[SATA]** and **Answer:** B.
Number using your assigned range. Write the file with the Write tool to the path you were given. Then reply with just: the file path and the count of SATA vs Single.
